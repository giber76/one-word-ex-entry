One word your ex would use to describe you — for make.fun's "One Word From
Your Ex" bounty ($2, free to enter, one winner takes all).

## The entry

**manchild**

One word, nothing else. It is exactly the word an ex would use: a grown man
who still needs looking after. It lands instantly, it stings because it is
painfully true, and it is funny because the entrant plainly knows it — no
synonym ("immature", "boyish", "irresponsible") carries the same picture.

## How it runs

`main.ts` writes the single word to `/output/entry.txt` (8 characters,
UTF-8, no trailing newline, no extra text). Run it with Node 22:

```sh
node main.ts
```
